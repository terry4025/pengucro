# 프로젝트 규칙 (Project Rules)

이 프로젝트는 방탈출 예약 매크로 프로그램입니다. 예약 엔진(예: Keyescape, Zeroworld 등)을 수정하거나 새로 구현할 때는 반드시 다음 규칙을 준수해야 합니다.

## 1. 구글 reCAPTCHA v2 처리 규칙
- **2분 만료 경고 출력**: 구글 캡차 토큰의 유효 시간은 2분입니다. 예약 2단계 대기 진입 시 아래의 경고 메시지를 로그에 경고(Warning) 등급으로 반드시 노출해야 합니다.
  > `[경고] 구글 캡차 인증은 완료 후 2분이 지나면 자동 초기화(만료)됩니다. 예약 오픈시간 1~2분 전에 완료하시는 것이 가장 안전합니다.`
- **하이브리드 바이패스 구조**:
  - 백그라운드에서 YesCaptcha 등의 API 자동 해결 태스크를 즉시 실행해야 합니다.
  - 동시에 브라우저 상의 수동 캡차 체크박스 클릭 여부도 실시간으로 모니터링해야 합니다.
  - API 자동 해결 토큰 주입 또는 사용자의 수동 체크 중 **더 먼저 완료되는 것**을 기반으로 즉시 대기/인증 상태를 통과시켜야 합니다.

## 2. 미오픈 날짜(정각 감지) 예약 제출 규칙
- **조기 제출 방지**: 임의 슬롯 값(`9999` 등)으로 진입한 경우, 캡차가 해결되더라도 즉시 예약하기 버튼을 눌러서는 안 됩니다.
- **실시간 백엔드 감시**: 0.15초 내외의 빠른 간격으로 백엔드 API를 조회하여 실제 예약 타임슬롯이 오픈되는지 감시해야 합니다.
- **동적 ID 치환**: 타임슬롯 오픈이 감지되는 즉시, API 응답으로 받은 실제 Slot ID를 브라우저 폼 필드(`themeTimeNum` 등)에 자바스크립트로 동적 교체(Inject)한 뒤 예약을 최종 제출해야 합니다.
