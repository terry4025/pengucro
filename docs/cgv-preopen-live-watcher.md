# CGV 미오픈 장기 감시 상태 모델

이 문서는 CGV IMAX 목표 날짜가 언제 열릴지 모르는 상태에서 Pengucro를 수시간~수일 실행할 때의 런타임 원칙을 기록합니다.

## 권위 데이터와 보조 신호

- `searchMovScnInfo`: 실제 예약 전환을 결정하는 유일한 권위 회차 데이터입니다.
- `searchSiteScnscYmdListByMov`: 영화/지점별 상영일 목록을 이용한 저빈도 조기 경보입니다. 이 응답만으로 예약 단계에 진입하지 않습니다.
- 보조 신호의 오류, timeout, 401/403/429는 메인 회차 감시를 중지시키지 않습니다.

## 장기 감시 cadence

1. 평상시 실제 회차 조회: 2.5초 간격, 1개 연결.
2. 다음 변화 중 하나가 보이면 90초 동안 0.5초 집중 감시:
   - 목표 영화가 목표 날짜 응답에 처음 등장
   - 회차 fingerprint 변화
   - 영화별 상영일 목록에 목표 날짜 등장
3. 90초 동안 실제 예약 가능한 목표 회차가 나오지 않으면, 영화 힌트가 계속 화면에 남아 있어도 2.5초 장기 감시로 자동 복귀합니다.
4. 실제 목표 회차가 완성되면 보조 센서보다 즉시 우선 처리합니다.

## 보조 센서 비차단 원칙

`movNo` 참고 날짜 탐색과 상영일 목록 요청은 페이지 내부 background fetch로 시작하고 기다리지 않습니다. 이후의 `searchMovScnInfo` tick에서 완료 결과만 읽습니다. 따라서 보조 API 지연이 다음 실제 회차 조회를 늦추면 안 됩니다.

## 예약 가능 판정

기존 preopen matching/funnel 규칙을 유지합니다.

- 목표 영화 일치
- 요청 IMAX/포맷 family 일치
- `siteNo`, `scnYmd`, `scnsNo`, `scnSseq` 완성
- 명시적인 `cntlYn=Y` 잠금 제외
- 참고 날짜 시간은 exact ID가 아니라 우선순위로 사용하고 실제 공개 회차에 드리프트 매핑

## 로그에서 확인할 핵심 전환

- `[CGV][미오픈 sentinel] 영화 ID 확보 ...`
- `[CGV][미오픈 sentinel] 준비 완료 ...`
- `[CGV][미오픈 sentinel] 목표 날짜 ... 게시 감지 ...`
- `[CGV][미오픈 판정] 전체 → 영화 → 관/포맷 → 회차ID → 판매가능 → 시간허용 → 최종`
- `[CGV][미오픈 선택] ... 다음 단계=관람인원/좌석 진입`

상영일 sentinel은 목표 날짜를 한 번 확인하면 이후 더 이상 polling하지 않습니다.
