# 단편선 병렬 제한 및 CGV 로그인 OCR 검증

작성일: 2026-09-07. 기준 커밋: `57059be4a0cfd8f4755e454674a0c3f62ce13a79`.
이번 변경의 배포 대상은 v6.83이다. 기존 v6.82 배포 파일은 덮어쓰지 않는다.

## 단편선

- 작업 슬라이더 기본 4, 최대 8. 저장된 32 설정과 UI를 우회한 시작 호출도 최대 8로 제한한다.
- 기존 프로그램별 HTTP 요청 제어, 429/5xx 감속, Retry-After 대기, 주문 중복방지는 유지한다.
- 다른 엔진의 병렬 제한을 변경하지 않는다.
- 사이트 또는 IP별 제한과 여러 프로그램의 합산 요청량은 별개다. 최대 8은 429 부재나 예약 성공을 보장하는 값이 아니다.
- 직전 실측에서는 32작업의 내부 대기 중앙값이 약 4.13초였으나 8작업은 약 0.45초였다. 유한한 비오픈 조회 측정이며 오픈 경쟁 부하의 최적값으로 일반화하지 않는다.

## 제로월드 추가 원본 1,000장

- 예약 폼 1회, 챌린지 초기화와 이미지 조회 각 1,000회: 총 2,001 HTTP 요청.
- 요청 시작 간격 최소 0.5초. 수집 중 비정상 HTTP 응답·타임아웃·중복이 발생하면 중단하는 방식.
- 실제 수집은 오류 없이 완료. 기존 800장과 추가 1,000장의 파일 해시는 서로 중복되지 않았다.
- 예약 생성, 결제, 정답 제출 요청은 0회. 이미지 및 챌린지 검증값은 로컬 `scratch`에만 보관한다.
- 기존 OCR을 별도 프로세스에 고정한 최초 검증: **996/1,000**. 실패: 233, 579, 719, 982번.
- 기존 인식 실패 시에만 원본 120x30 비율의 두 모델 검사를 추가했다. 숫자를 열거하거나 정답을 하드코딩하지 않는다.
- 보정 후 고정 원본 재검증: **999/1,000**, 719번은 여전히 인식 불가. 해당 원본을 바꾸거나 실패를 제외하지 않았다.
- 기존 4개 코퍼스 합계 **800/800** 회귀 통과. 전체 보유 원본은 1,800장이지만, 보정에 사용한 표본의 재검증을 독립적인 최초 정확도로 표현하면 안 된다.
- 제로월드 검증은 이미지 OCR 후보와 사이트 챌린지 digest의 일치 확인이다. 단일 모델 첫 후보의 정확도나 실제 예약 성공률이 아니다.
- 보정 후 새 1,000장의 인식 시간: 중앙값 14.50ms, p95 90.66ms, 최대 938.22ms. 모델 예열 이후 로컬 측정값이다.

## CGV 로그인

[공식 로그인 페이지](https://cgv.co.kr/mem/login?nmbrAtktFlag=Y)의 실제 DOM을 확인했다.

- 아이디 `#loginInput1`, 비밀번호 `#loginInput2`, 숫자 `#loginInput3`, 240x95 캔버스의 6자리 숫자다.
- 제로월드의 4~5자리 digest 검증과 다르므로 정답 검증 방식을 복사하지 않았다. 기존 두 OCR 모델과 숫자 디코더를 재사용하되, CGV 경로만 6자리로 읽는다.
- 실제 글자 영역을 처리하고 두 모델의 첫 후보 일치를 요구한다. 일치하지 않으면 제한된 흑백 전처리 결과까지 비교하며, 불확실한 경우 입력하지 않는다.
- Chrome 1번 슬롯 선택과 기존 프로필·세션 재사용 정책은 변경하지 않는다. 사용자가 확인한 Chrome 자동완성 값을 사용하고 계정 정보를 따로 저장하거나 읽어 로그로 남기지 않는다.
- 아이디·비밀번호가 비어 있거나 편집 중이면 대기한다. 사용자가 이미 입력한 숫자는 덮어쓰지 않는다.
- 숫자를 인식하는 동안 이미지나 입력 상태가 달라지면 제출하지 않는다. 한 번의 로그인 대기에서 자동 로그인 제출은 최대 1회다.
- 로그인 버튼 클릭 이후 예외나 불명확한 응답이 발생해도 자동 재전송하지 않는다. 기존 회원 세션 및 API 인증 확인 경로를 유지한다.
- 예약 시작, 회원 세션 만료 후 방문자 선택, 좌석도 조회의 로그인 대기에 연결했다. 좌석도 로그인 대기에서도 취소 신호를 확인한다.

검증 결과:

- 실제 페이지에서 확보한 16개 이미지: **15개 정확, 1개 판단 보류, 잘못된 답 반환 0개**. 이 중 전처리 변경 이후 추가 확보한 10개는 10개 모두 정확했다.
- 사람의 이미지 판독과 비교한 소표본 결과이며, CGV 전체 정확도나 100% 자동 로그인을 보장하지 않는다.
- 별도 Chrome 프로필과 로컬 응답으로 DOM 검증: 정확한 이미지 3건은 input 이벤트와 로그인 클릭 각 1회, 불확실한 이미지 1건은 둘 다 0회.
- 실제 사용자 계정의 로그인 완료 및 예약·결제는 이번에 실행하지 않았다. 현재 실행 중인 사용자 프로그램과 예약 탭을 중단하거나 변경하지 않았다.

로컬 증거: `scratch/cgv-login-ocr-check/results.json`, `scratch/cgv-login-ocr-check/dom-results.json`.
